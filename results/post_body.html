Reading the Activation, Not the Prior

Project · Mechanistic interpretability, Llama 3.1 8B

Summary

I reproduced the main result from Self interpretation in language models via adapter probes and then ran an extension to test something the paper leaves open. The paper trains a tiny adapter, as few as d+1 parameters, that maps a model's internal activation back into its own embedding space so the model can describe what that activation represents. In my reproduction it reaches 79.3% recall@1 over 49,637 candidate topics, against 0.0% for an untrained baseline.

My main critique is that I do not think the current evaluations fully establish that the model's self interpretation results from faithfully analyzing the specific input activation rather than from information in the model or adapter's existing semantic priors. The paper shows that the descriptions correspond well to the activations, but it does not test how the descriptions respond when you make a controlled change to the activation itself. To test this, I took an activation, added a steering direction for a known concept at varying strength, and measured whether the description moved toward that concept. I also verified separately that the same intervention changes the model's behavior, which gave me a baseline for how much the description should move.

It does move, and the effect holds up under the checks I care about. Adding the direction shifts the description toward the concept while subtracting it shifts the description away, and a random direction of the same size does nothing, so the response is specific to the direction I chose rather than to disturbance in general. The description also shifts at the same intervention strength that changes the model's behavior. While I think that is real evidence, the effect is small once you measure it against everything else that moves a description around, and getting to the answer at all meant catching two problems in my own setup that would each have produced a confident false positive.

The reason this question interests me is that self interpretation would make mechanistic interpretability much more scalable. A lot of current interpretability work involves getting humans or other models to label internal features, which is noisy and slow, and having the model help interpret its own activations could make that process much faster and more reliable. If we want to use the methodology for alignment, though, and specifically to prevent deceptive alignment, we would need evidence that the model's interpretation actually tracks the internal state rather than just what the model wants to output. That is the gap I was trying to close, and this closes part of it rather than all of it.

High level takeaways

  1. The description tracks controlled changes to the activation. Adding a concept direction moves the description toward that concept and subtracting it moves the description away, while a random direction of the same size does nothing at all. Under a paired bootstrap over 40 concepts the difference holds at every non zero strength (p < 0.0001 throughout), and it sits at exactly zero when I add nothing, which is the sanity check I most wanted to pass.

  2. The self interpretation tracks behavior almost point for point. Plotting the description curve against the behavioral curve across the same steering strengths gives a correlation of 0.997, with a mean absolute difference of 0.022. A description that only responded to large interventions would produce a flatter curve that rises later than the behavioral one, and that is not what happens here.

  3. The learned prior carries no information about the specific activation. Given the zero vector, the adapter still produces fluent and oddly specific descriptions that identify nothing, at 0.0% recall@1. This agrees with the paper rather than contradicting it, since the authors already say the bias supplies format while the activation supplies meaning. What I would add is that the bias does not simply produce vague or hedged text when it has nothing to work with. It invents specific people, films and dates that do not correspond to anything.

  4. Which activation the description started from still dominates what it says, far more than the steering direction does. The steering coefficient accounts for 0.74% of the variance in description embeddings, against 37.8% for the identity of the activation itself. That number needs care in how it is read. Most of the remaining spread, 60%, is sampling randomness at temperature 0.5 rather than a competing explanation. Descriptions also differ from each other for many reasons at once, including which topic they cover and how they happen to be phrased, and the steering coefficient only moves them for one of those reasons. A description shifting from Arabic classical music to Arabic language cinema answers exactly the question I was testing, even though that shift is small next to everything else that makes two descriptions different.

Background

Most interpretability work asks a human or a separate model to label internal features, which is slow and noisy, so this approach asks the model to do it instead. Following the Patchscopes framing, you extract an activation from some layer, transform it with a learned mapping, and inject the result as a soft token into a fixed explanation seeking prompt, "What is the meaning of ___?". The frozen model then decodes it autoregressively.

The mapping has deliberately few parameters. The scalar affine version is

f(h) = α · (h / ‖h‖) + b

That is one scalar and one bias vector of 4096 dimensions, so 4097 parameters in total, against roughly 16.8 million for a full rank affine map. The authors argue that this constraint is the point, since a mapping that scales every direction identically has almost no capacity to memorise a special case for any particular vector, which is why the smallest adapter generalizes better than more expressive ones. Two properties matter for everything below. The adapter L2 normalizes the activation before scaling, so only its direction carries information while its magnitude is discarded. The bias b is constant across all inputs, which makes it a learned prior over how to answer.

The paper reports that this bias accounts for roughly 85% of the improvement over an untrained baseline, and reads it as the bias supplying format while the activation supplies meaning. They back that up with a zero vector test and, more convincingly, by training on labels written in capitals and showing the outputs come out both capitalized and semantically correct. Worth being precise about what they claim, since it is narrower than it first sounds. They do not say the prior does most of the semantic work, and my results agree with them.

None of the paper's evaluations intervene on an activation. Every result has the form "descriptions match activations across many examples", which is also what you would observe if the model had simply learned a good prior over what activations in this distribution tend to mean. The two cases only come apart once you change an activation on purpose and watch what the description does.

I first tried to settle this from the adapter's parameters alone, since both terms are just numbers in a checkpoint. Because the adapter L2 normalizes the activation, that term always has the same magnitude, α=7.175, against a bias norm of 20.869, which puts the activation at roughly 10.6% of the soft token and confines every soft token the model can receive to a cone of 40 degrees. That settles nothing, because the paper reaches 79.3% recall@1 over 49,637 topics using only the directions inside that cone. The geometry bounds how much room the activation has rather than how well the model uses it, and separating those two questions is what convinced me the experiment was necessary.

Method

Setup

I ran everything on Llama 3.1 8B Instruct, reading activations from the layer 19 residual stream and using the adapter checkpoints the authors released. I trained nothing myself, so this reproduces their artifact rather than their training run. All scoring uses GTE large, the same embedding model they used. The final sweep is 134,406 generations, run on a single rented GPU for a few dollars of compute.

The research question, the critique of the paper, and the experimental design are mine. I wrote the implementation with Claude Code, which accelerated the work considerably while still requiring continuous direction. Most of what follows came from interrogating outputs from Claude that did not look right. The two errors in What went wrong are ones I caught by asking why a number looked the way it did.

Where the steering directions come from

I needed steering vectors that correspond to nameable concepts, so the model has vocabulary to report them, and that demonstrably change behavior, so I have an independent baseline. I used AxBench CONCEPT500, which gives me, for each of about 2000 concepts, example responses that express it and example responses that do not. Its concepts come from GemmaScope auto interp labels, so they sit in the same descriptive register the adapter was trained on. That matters, because a concept the model cannot name gives you a null result you cannot interpret.

I checked the data before using it, and that is where the first problem showed up.

Failure mode in the data

Every positive example is written in the same voice. An LLM generated AxBench's positives to express a concept, while the negatives are ordinary responses, which leaves the positives sharing a flowery register that the negatives lack. The word "akin" shows up in 17.2% of positives and 0% of negatives. Positives run 46% longer.

I measured how bad this is by training a classifier on some concepts and testing it on concepts it had never seen. It still separates positives from negatives 97% of the time, on style alone. A difference of means steering vector, mean positive minus mean negative, would encode "AxBench voice" rather than the concept. Worse, since style is a real and consistent direction, that vector would have passed my random direction control. I would have reported a confident false positive.

The fix is the same mean ablation the paper applies to its own contrastive topic vectors. Subtracting the mean across all concepts cancels the shared component and leaves what is distinctive to each one. I also switched to building vectors from positives only rather than positives minus negatives, because the two sets of questions turn out to be completely disjoint. Subtracting one from the other would build in a difference between two sets of questions rather than between two sets of answers.

What surprised me most was the gap between the text level check and the real thing. Measured on the text, the shared component looked like 23% of a typical vector. Measured on the actual Llama activations, it was 96%. Every concept vector was very nearly the same vector, with gambling and plant virus classification sitting at 0.92 similarity. After subtracting the average they become essentially unrelated, the leftover similarities turn semantically sensible, and rebuilding each vector from a different half of its examples gives a 0.94 match. I think that lesson generalizes. Checking on the text underestimated the problem by a factor of four, because two passages can share a tone without sharing much vocabulary, while the activations encode that tone directly. A confound is worth measuring on the activations themselves rather than on the text they came from.

How I scored "does this look like the concept?"

The obvious method, measuring similarity between the description and the concept, is not trustworthy. That number drifts upward whenever the text becomes longer or vaguer, which means generic filler would register as success. I made it a multiple choice question instead. Embed the description, embed the right concept's label and 40 other concept labels, then take the cosine similarity between the description embedding and each label embedding. The score is the fraction of the 40 alternatives that the correct label beats, so chance sits at 0.5. Generic drift lifts the right answer and the wrong answers together, so it cancels.

I tracked three further measures as checks. The first is a keyword match rate computed by substring matching, which uses no embeddings at all, so the result does not rest entirely on one embedding model. The second and third are degeneration measures, specifically bigram diversity and the per token negative log likelihood of the output under the unsteered model. The last is similarity to the description's original topic, which lets me observe the tradeoff rather than only the gain.

Key experiments and results

1. Does the released adapter work, and what does the prior say alone?

The paper reports 82.9% recall@1. I obtain 79.3% on a 1000 topic sample, which I consider a clean reproduction. Picking k topics at random out of 49,637 finds the right one k/49,637 of the time, which puts chance at 0.002% for recall@1 and 0.2% for recall@100. The untrained version's 2.0% at recall@100 is therefore about ten times chance, and still carries no useful signal.

Finding · the reproduction holds, and the learned prior identifies nothing on its own while producing confident fabrications. "The bias accounts for 85% of the improvement" is fully compatible with the bias knowing nothing about the specific activation, which is what the authors say and what this measures.

2. Do the steering directions actually change behavior?

This step is what separates the rest of the work from a correlation. Before touching self interpretation at all, I added the direction into the residual stream during ordinary generation and measured whether the answers changed, and whether the model was still producing coherent English.

The failure mode worth noting is that at λ=2 the concept score sits near its maximum, precisely because the output has degenerated into nothing but concept keywords. The concept metric looks best exactly where the model has most thoroughly broken. Without the coherence measure I would have read that as my strongest result rather than the point of collapse.

Finding · the intervention is behaviorally real and monotone, but only strengths up to about 1 are interpretable. Past that I am measuring damage, so I restricted the rest of the analysis to that band.

3. Does the self interpretation follow?

The main experiment. For each activation I added the concept direction at seven strengths across 40 concepts, ran the result through the adapter, injected it, and generated six descriptions. Because the adapter normalizes its input, adding a direction can only rotate it and never change its size, so no size confound can explain the result. That is a useful property of this adapter form that I did not expect going in.

I ran three controls alongside, each aimed at a specific way the main result could be spurious.

ControlThe worry it rules out
random directionthe description changes whenever you disturb the activation at all, with nothing to do with meaning
shared voice directionthe description follows any real and consistent direction. A random vector cannot test this, since the model has never represented one
steering vector aloneat high λ the activation gets drowned out and the adapter is decoding the steering vector rather than the activation

Reading across, the concept curve climbs steadily and moves both ways. Push the activation toward the concept and the description follows. Push it away and the description moves away. Both controls sit flat. For significance I used a paired bootstrap, pairing by concept. Each of the 40 concepts is scored twice, once with its steering direction added and once with a random direction added, so I take the difference within each concept and end up with 40 numbers instead of two groups of 40. Resampling those 40 differences with replacement 10,000 times shows how far the average would move if I had drawn a different set of concepts. Pairing this way matters because the two conditions are correlated across concepts (r = 0.31), meaning some concepts are simply easier to score than others, and taking the difference within a concept removes that shared component. This is easiest to read from the middle outward. With no nudge the model gets the topic right, and once I add a little the word Arabic survives while the domain slides from music to cinema, so the output blends the activation with the direction rather than replacing one with the other. Subtracting does the mirror image, since Arabic still survives while the domain slides toward textiles and away from film. If I push too far in either direction the topic washes out entirely and I am left with pure concept on one side and unrelated content on the other, which is exactly what the nudge alone control predicts and why I only trust the middle of the range.

Finding · the description tracks the activation, specifically and in both directions, and a random direction of the same size does not reproduce it. At λ=0.3 the concept curve sits at 0.49 while the steering vector alone reference is already at 0.97, so the activation is still doing most of the work. I capped the grid at λ=1 for exactly this reason.

4. Does it follow at the right strength, and how large is the effect?

Both experiments use the same λ scale and the same 40 concepts, so I can plot them against each other directly.

I expected the two to line up at roughly the same point. I did not expect them to lie almost on top of each other. Their λ50 values are 0.557 and 0.517, and across all seven coefficients the curves differ by an average of 0.022. This is the result I find most persuasive in the whole project, because a report that only registered gross changes would have produced a visibly flatter or delayed curve.

Finding · the self interpretation shifts at the same intervention strengths that change the model's outputs, and by closely matching amounts, rather than trailing behind.

The harder question is how much of the output this actually accounts for, so I decomposed the variation between descriptions into the components that explain it, which are the shared constant every description carries, which activation it started from, which concept I used, the nudge itself, and plain sampling randomness.

I want to be careful reading this in both directions. The steering coefficient accounts for under 1% of the variation and the activation's identity for 38%, so what a description mostly says depends on which activation it describes rather than on what I added to it. At the same time, 60% of the remaining spread is sampling randomness at temperature 0.5, which is measurement noise rather than a rival explanation for the output. The deeper issue is that descriptions differ from each other along many dimensions at once, covering which topic they name, which entity they pick, and how they are worded, while the steering coefficient only pushes them along one of those. That is why the shift from Arabic classical music to Arabic language cinema can be obvious to a reader and still register as a small fraction of the total variation.

Finding · the effect points consistently in the right direction and holds up statistically, and it still is not what dominates what the model says. I think both halves of that need reporting.

What went wrong, and how I caught it

I found two of these only because a number did not look right and I followed it up. I think they are the most useful part of this project to document, since both are easy mistakes to make.

Error 1 · a control that could not have detected anything

My shared voice control returned 0.5000000000 at ten of the eleven strengths I tested. A genuine measurement does not behave that way, so I investigated.

The shared voice direction is a single vector used for every concept, so for any given activation it produces the identical description across all of them. I then scored that one description against each concept in turn, each against the others, which counts every ordered pair exactly once and forces the average to exactly a half. The number was arithmetic rather than measurement.

That control would have read 0.500 even if the direction had shoved every description toward one concept, and I had been treating it as my strongest control. The fix is to draw the comparison pool from concepts outside the set being tested, so wins and losses cannot cancel. Once I did that the control gave a genuine flat result instead of a forced one. The general lesson is that a rank against alternatives metric needs its targets and its alternatives drawn from separate sets.

Error 2 · a filter that selected against its own effect

I gated concepts on staying coherent across the whole range of strengths, including the extremes I then excluded from interpretation anyway. Only 11 of 60 concepts survived. If you gate on the range you actually analyze, all 60 qualify.

The filter was not merely wasteful, it was biased. Steering hard and breaking the model at high strength are the same phenomenon, so "still coherent at strength 2" preferentially kept the concepts that do not do much. Concepts that survived the strict gate had a median behavioral effect of 0.283. The ones it excluded had 0.526. My filter was quietly selecting against the effect I was trying to measure, and it cost me roughly half the observable effect size.

Limitations and future work

  • This is a sensitivity test, not a causal one. Steering vectors are not clean semantic representations, so showing the description responds to one is weaker than showing it correctly reports a change whose internal role we already understand. Next step. Intervene on a feature or circuit whose causal role is independently established, such as the name mover heads in the IOI circuit, and test whether the self interpretation describes that.

  • I selected favorable concepts twice. First for being clean in the data, then for steering well without breaking fluency. These results describe the favorable case rather than the average concept. Next step. Report the full distribution across all screened concepts, including the ones that barely steer.

  • One confound in the data survives. AxBench's positive and negative examples answer completely different questions, and those questions were selected to suit their concept, which leaves the vector blending the concept in the response with the topics of its prompts. Subtracting the average cannot fix this, because the question content is itself tied to the concept. Next step. Add a control built from the questions alone, to bound how much of the effect comes from prompt topic.

  • I only tested one setup. Everything here runs on a single model at a single layer with one adapter architecture, so I do not know how far it generalizes. The adapters trained on sparse autoencoder features give their activation term less than half the relative size that the topic adapter does, which I would expect to change the answer. Next step. Repeat on the Goodfire and Llama Scope adapters, and at a second layer.

  • Small effect size and a modest sample. Confidence intervals over concepts are wide because the concept is the unit of replication and there are not many of them. Next step. Run more concepts, which is cheap now that the coherence gate is fixed.

  • Scoring leans on one embedding model. The same embedder scores the screen that selects concepts and the sweep that measures the effect. My string matching check agrees with it, which is reassuring, but the two are not independent enough for me to rely on. Next step. Score with a second embedder and an LLM judge.
